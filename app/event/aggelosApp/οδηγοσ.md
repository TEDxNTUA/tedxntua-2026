# 🚀 TEDx App — Πλήρης Οδηγός Setup (1 ώρα)

## Δομή αρχείων
```
tedx-full/
├── index.html          ← Η εφαρμογή
├── sw.js               ← Offline cache
├── manifest.json       ← PWA manifest
├── sponsors.pdf        ← ΤΟ PDF ΣΑΣ (προσθέστε το εδώ)
├── icons/
│   ├── icon-192.png
│   └── icon-512.png
└── photos/             ← Φωτογραφίες ομιλητών/performers
    ├── s1.jpg, s2.jpg, ... s6.jpg   (ομιλητές)
    └── p1.jpg, p2.jpg               (performers)
```

---

## ΒΗΜΑ 1 — Συμπληρώστε τα δεδομένα στο index.html (~20 λεπτά)

Ανοίξτε το `index.html` και βρείτε `const CONFIG = {`

### Πρόγραμμα (schedule):
```js
{time:"09:45", title:"Τίτλος ομιλίας", speaker:"Ονοματεπώνυμο",
 initials:"ΟΑ", speakerId:"s1", tag:"Τεχνολογία"},
// Για performance αντί για speakerId βάλτε performerId:"p1"
// Για διάλειμμα: {time:"10:00", title:"Διάλειμμα", type:"break"}
```

### Ομιλητές (speakers):
```js
{id:"s1", name:"Ονοματεπώνυμο", role:"Τίτλος/Θέση",
 photo:"photos/s1.jpg",   // ← βάλτε ίδιο όνομα με το αρχείο
 talkTitle:"Τίτλος ομιλίας",
 tag:"Κατηγορία",
 bio:"Βιογραφικό και περιγραφή ομιλίας..."},
```

### Performers:
```js
{id:"p1", name:"Όνομα", role:"Είδος", photo:"photos/p1.jpg",
 tag:"Μουσική", desc:"Περιγραφή performance..."},
```

### Workshops (ΜΗΝ αλλάξετε τα seats — είναι ήδη σωστά):
```js
// Professional = 40 θέσεις, Experience = 15/30/15
// Αλλάξτε μόνο: name, time, desc
{id:"wp1", name:"Σωστό Όνομα Workshop", time:"11:00 – 12:30", desc:"..."}
```

### Giveaways:
```js
{id:"gw1", name:"Giveaway #1", prize:"🎁 Περιγραφή δώρου"}
// Προσθέστε/αφαιρέστε giveaways ελεύθερα
```

### Admin κωδικός:
```js
adminPass: "ΑΛΛΑΞΤΕ_ΤΟΝ_ΚΩΔΙΚΟ_ΣΑΣ",
```

## ΒΗΜΑ 2 — Φωτογραφίες ομιλητών
- Ονομάστε τα αρχεία: `s1.jpg`, `s2.jpg`, κλπ (ή `p1.jpg` για performers)

## ΒΗΜΑ 3 — Firebase Setup (~10 λεπτά)

1. → **https://console.firebase.google.com** → Add project → `tedx-peristeri-2025`
2. **Firestore Database** → Create → **Test mode** → Region: `eur3`
3. **Project Settings (⚙️)** → Web app (`</>`) → Register → Αντιγράψτε config
4. Στο `index.html` βρείτε `const cfg={` και αντικαταστήστε:
```js
const cfg = {
  apiKey: "AIza...",
  authDomain: "tedx-peristeri-2025.firebaseapp.com",
  projectId: "tedx-peristeri-2025",
  // κλπ
};
```

### Firestore Security Rules (αντιγράψτε στο Firebase Console → Rules):
```
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /workshop_registrations/{doc} {
      allow read: if false;
      allow create: if request.resource.data.name.size() > 1
                    && request.resource.data.email.matches('.*@.*')
                    && request.resource.data.ticket.size() > 0;
    }
    match /giveaway_entries/{doc} {
      allow read: if false;
      allow create: if request.resource.data.name.size() > 1
                    && request.resource.data.email.matches('.*@.*');
    }
  }
}
```

## ΒΗΜΑ 5 — Deploy στο Netlify (~3 λεπτά)
1. → **https://app.netlify.com/drop**
2. Σύρετε ολόκληρο τον φάκελο `tedx-full/`
3. Παίρνετε URL π.χ. `https://sparkling-unicorn-abc.netlify.app`
4. (Προαιρετικά) Settings → Domain → αλλάξτε σε `tedxperisteri2025.netlify.app`

## Admin Panel — Πώς λειτουργεί

**Πρόσβαση:** Πατήστε **5 φορές γρήγορα** το λογότυπο TEDx

**Λειτουργίες:**
- 🎲 **Κλήρωση**: Επιλέξτε giveaway → "Κλήρωση Νικητή" → εμφανίζεται τυχαίος νικητής με animation
- 📋 **Εγγραφές**: Βλέπετε όλες τις εγγραφές workshops (όνομα, εισιτήριο, email) ανά workshop
